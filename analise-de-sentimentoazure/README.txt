Análise de Sentimentos com Azure AI Language Studio

📄 Descrição

Este projeto tem como objetivo demonstrar a aplicação prática da ferramenta Azure Language Studio para realizar análise de sentimentos em textos. A atividade faz parte do curso da DIO e visa aprofundar conhecimentos em IA aplicada à linguagem natural.

🧱 Tecnologias Utilizadas

Azure Language Studio

Azure Speech Studio (opcional)

GitHub para documentação

✅ Etapas Realizadas

Acesso ao Azure Language Studio

Criação de projeto de Análise de Texto

Inserção de dados de exemplo (frases com sentimentos variados)

Execução da análise de sentimentos

Interpretação dos resultados gerados (positivo, negativo, neutro)

📊 Exemplo de Resultado

Texto analisado: "O atendimento foi rápido e muito gentil."
Resultado: Sentimento Positivo

Texto analisado: "Demorou muito para resolver meu problema."
Resultado: Sentimento Negativo
